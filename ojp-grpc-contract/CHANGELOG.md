# Changelog

All notable changes to the OJP gRPC contract distributed by this package are documented
here. Versions follow the wire-compatibility policy described in `README.md`.

## 1.0.0

Initial extraction of `StatementService.proto`, `echo.proto`, and `containers.proto` into
their own versioned package. The files are byte-identical to the corresponding sources in
`ojp-grpc-commons/src/main/proto` as of the `ojp` `main` branch at commit `7b86a25d`.
