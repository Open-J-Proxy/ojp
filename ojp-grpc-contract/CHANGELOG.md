# Changelog

All notable changes to the OJP gRPC contract distributed by this package are documented
here. Versions follow the wire-compatibility policy described in `README.md`.

## 1.0.0

Initial extraction of `StatementService.proto`, `echo.proto`, and `containers.proto` from
the Java commons module into the versioned shared contract package. The files match the
OJP `main` branch at commit `7b86a25d`.
